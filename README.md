# zmq-mobile

Pre-built static zmq libraries for android (`arm64-v8a`, `armeabi-v7a`, `x86_64`) and iOS,
Based on `zmq` version `4.3.5`.  
`build-zmq-android.yml` defines the workflow for the android build.
`build-zmq-ios.yml` defines the workflow for the iOS build. It uploads the resulting `xcframework` as a Github artifact.
